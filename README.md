## 🎮 Interactive Features

- **Matrix Rain** — Three.js-powered particle systems and matrix digitfall
- **3D Particle Cloud** — 12,000 particle WebGL visualization
- **Repo Grid** — Filterable, searchable repository browser with live GitHub API
- **Command Line** — `ls`, `hack <name>`, `filter <lang>`, `breach` commands
- **Deviant Mode** — Toggle "BREACH PROTOCOL" for alternate cyberpunk theme
- **Live Stats** — Real-time repository counts, languages, stars
